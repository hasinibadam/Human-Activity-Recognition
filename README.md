# Human-Activity-Recognition
HAR uses sensor data from smartphones (accelerometer and gyroscope) to detect human activities.

The dataset contains 561 features and 6 activity classes: Walking, Walking Upstairs, Walking Downstairs, Sitting, Standing, Lying.

Data needs preprocessing: scaling numeric features and encoding activity labels.

Multiple machine learning models can be trained, e.g., Decision Tree, Random Forest, SVM.

Evaluation metrics like accuracy, precision, recall, and F1-score help compare model performance.

Confusion matrices visualize correct vs misclassified activities.

Random Forest generally gives highest accuracy, but SVM and Decision Tree are also useful for comparison.
